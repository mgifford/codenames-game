Codenames Codenames — the board game by Vlaada Chvátil, published in 2015 by Czech Games Edition.

Click New Game to create a server-based game. Other players can join at any time once a game is created.

To play without a server using a direct P2P connection, use the P2P Mode button — works on GitHub Pages and on local networks.

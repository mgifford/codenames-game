No game server needed. This game uses PeerJS, a library built on the browser's built-in WebRTC standard. Once two players are connected, all game messages travel directly between browsers — no cloud server is involved in gameplay.

What internet access is needed?

  • Initial connection only (a few seconds): PeerJS contacts a free signalling server (0.peerjs.com) to exchange the connection handshake between players. This takes only a moment.
  • After the handshake, no internet is used. All game data flows peer-to-peer between the players' devices.

Can two phones play without internet?

  • Yes, on a shared local network (same Wi-Fi or one phone acting as a mobile hotspot): once the initial handshake succeeds, game traffic stays entirely on that local network.
  • Hotspot tip: If one phone shares its mobile data as a hotspot, the other phone connects to it. The hotspot provider's internet is used only for the ~2-second PeerJS handshake; after that, all game traffic stays on the hotspot network itself.
  • Completely offline (no shared network): Not supported out of the box. A local peerjs-server on the same LAN removes the internet dependency entirely — see the local gaming guide for details.
